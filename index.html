🔁 What ConvertXR does

Pick a file, pick a format, tap Convert. Images convert instantly with the browser's canvas. Video and audio convert with ffmpeg running inside this page (WebAssembly) — the first video/audio conversion downloads the ffmpeg engine (~31 MB) once, then it's cached.

Everything happens on this device. No uploads, no server, no account, no cost. Your file never leaves the browser.

Honest limits: conversion speed is phone/headset-class, not desktop-class. Very large files (over ~200 MB) can run the browser out of memory — you'll get a warning first, and a crash guard saves the error below if it happens.
